# 测试计划

## 功能用例

1. 上传 `demo_files/sample_risky_contract.txt`，应命中付款周期和违约金风险，且每条有来源编号。
2. 上传 `sample_compliant_contract.txt`，不应凭空生成语义风险。
3. 删除违约或终止条款，检查缺失条款的建议关注提示。
4. 上传两个版本，调用 `/api/contracts/compare`，只返回变更条款。
5. 上传含“待定 / 以双方另行协商”的文本，检查人工审阅标记。
6. 法务调用 `/api/audit-results/{id}/review`，检查状态与备注落库。
7. 管理员新增规则后重新审查，检查规则命中。
8. 下载 PDF，检查报告内容和免责页脚；PDF 依赖缺失时检查 Markdown 降级。
9. `uploader` 访问他人合同和规则写接口应分别返回 403。
10. 从合同列表点击行尾箭头进入 `/contracts/{id}`，刷新后仍能恢复详情；在原始全文和结构化条款之间切换，风险项应显示规则/知识库来源与修改建议。
11. 法务逐条选择“属实/不属实”并填写意见，未完成全部判定时整体提交按钮禁用；提交后合同进入“复核完成”，状态时间线记录操作人和时间。
12. 选择两个版本生成差异，新增内容为绿色、删除内容为红色、修改内容为黄色；无差异时显示空状态。
13. 首页“上传合同”打开弹窗，只允许选择 PDF/DOCX；上传时显示进度，上传完成后显示解析阶段，错误文件返回友好错误提示。
14. 页面加载显示骨架占位；成功、警告、错误分别显示对应 toast；空合同、空知识库和无差异均显示空状态。

## 管理员系统设置用例

1. 使用法务账号登录：导航栏不显示“系统设置”；手动输入 `/system-settings` 后应被拦截并跳转到总览，页面提示“您没有管理员权限”，同时管理员 API 返回 403。
2. 使用 `admin / Admin123!` 登录：导航栏显示“系统设置”；完成业务规则的新增、编辑与禁用，上传能命中该规则的合同，验证保存后无需重启即生效。
3. 管理员新增并启用知识库条目，上传相关合同，验证 RAG 可检索到新条目；禁用后验证 RAG 不再读取该条目。
4. 管理员新增账号并分配 `uploader`、`legal_reviewer` 和 `admin` 角色，分别登录验证权限；禁用账号后验证无法登录，重置密码后验证旧密码失效且数据库仅保存 bcrypt 哈希。
5. 管理员修改 LLM API、Chroma、上传存储路径和 AI 风险阈值，点击保存后显示成功提示；刷新页面后配置值保持一致。

## 异常用例

损坏或伪造 PDF、损坏 DOCX、DOCX 解压体积异常、空文件、超 20MB 文件、包含 NUL 的文本、解析失败重试、LLM 超时部分结果、Chroma 故障回退 SQLite 检索、绝对/越界上传路径配置、越权 API 均需保留用户可理解的错误信息。
