# 成本测算

以下为 2026 年项目规划用的区间估算，金额以人民币计，实际价格以云厂商、模型供应商和并发量报价为准。公式和假设公开，便于替换参数重新测算。

## 场景假设

- 小型团队：10 名内部用户，每月 500 份合同、平均每份 20 页。
- 中型团队：50 名用户，每月 3,000 份合同、平均每份 25 页。
- 生产环境保留原文、条款、风险和操作日志 12 个月。
- 下面不包含一次性产品研发人力、法务标注和企业采购流程成本。

## 月度运行成本区间

| 成本项 | 本地演示 | 小型团队（云） | 中型团队（云） | 说明 |
| --- | ---: | ---: | ---: | --- |
| 应用计算 | 0 | 300-800 | 1,000-3,000 | 2-4 vCPU，按可用区和时长变化 |
| 数据库/备份 | 0 | 100-400 | 500-1,500 | SQLite 可迁移至托管 PostgreSQL |
| 文件存储与流量 | 0 | 50-300 | 300-1,200 | 与合同页数、保留周期相关 |
| Chroma/向量服务 | 0 | 0-500 | 500-2,000 | 本地 Chroma 或托管向量库 |
| LLM 推理 | 0 | 500-3,000 | 3,000-15,000 | 取决于模型、token 和是否自托管 |
| 监控、日志、安全 | 0 | 100-500 | 500-2,000 | WAF、审计、杀毒、告警 |
| **月度合计** | **0** | **1,050-5,500** | **5,800-24,700** | 估算区间，不含研发人力 |

## 计算公式

```text
月度 LLM 成本 = 合同数 × 每合同输入 token × 输入单价
              + 合同数 × 每合同输出 token × 输出单价

月度存储成本 = 月新增文件 GB × 保留月数 × 单价
             + 备份副本 GB × 备份单价

总成本 = 计算 + 数据库/备份 + 存储流量 + 向量服务 + LLM + 安全运维
```

## 降本策略

1. 默认 `CHROMA_ENABLED=false` 的本地 SQLite 检索适合开发和小规模演示，避免空闲向量服务成本。
2. 规则引擎先筛选条款，只将命中或需要语义判断的片段送入 LLM，减少 token。
3. 对相同条款和知识库结果做缓存；批量任务使用队列和限流，避免突发并发。
4. 生产环境将原文与报告转入低频对象存储，数据库只保留索引、条款、风险和审计记录。
5. 以人工复核通过率、每合同 token、P95 审查耗时和失败重试率作为成本与质量共同指标。

## 上线前成本核验

- 用真实脱敏样本统计平均页数、输入/输出 token 和 OCR 占比。
- 对 LLM、向量库、对象存储和杀毒服务分别获取正式报价。
- 为峰值并发、备份保留、跨区容灾和安全审计预留 20%-30% 预算。
